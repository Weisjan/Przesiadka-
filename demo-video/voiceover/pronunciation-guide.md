# Wymowa narracji

Wskazówki redakcyjne dla polskiego głosu. Przed eksportem odsłuchaj wybrany model; zapis fonetyczny jest przybliżeniem, nie deklaracją jednolitego standardu. Nie dodawano tagów phoneme specyficznych dla dostawcy.

| Zapis | Proponowana wymowa |
|---|---|
| GTFS | gie-te-ef-es |
| API | ej-pi-aj |
| REST API | rest ej-pi-aj |
| React | ri-akt |
| TypeScript | tajp-skrypt |
| Python | pajton |
| FastAPI | fast ej-pi-aj |
| SQLite | es-kju-el-lajt |
| OpenRouteService | ołpen rut serwis |
| SKM | es-ka-em |
| ZTM | zet-te-em |
| MVP | em-wi-pi |

Nazwy miejsc czytaj po polsku: Wrzeszcz, Gdańsk Główny, Dworzec Główny, Przegalina. Przegalina: prze-ga-LI-na; Wrzeszcz jest jednosylabowe. Numer słupka „08”: „zero osiem”, linia „112”: „sto dwanaście”. Nie spolszczaj nazw w napisach ani identyfikatorach.

Godziny i datę rozwinięto już słownie w finalnym tekście: 17:02 to „siedemnasta zero dwa”, 17:09 „siedemnasta zero dziewięć”, 17:16 „siedemnasta szesnaście”, 18:21 „osiemnasta dwadzieścia jeden”. W zdaniach zachowaj istniejącą odmianę („o siedemnastej…”). Liczby dodatnie i ujemne odnoszą się do zapasu, nie rzeczywistego opóźnienia pojazdu.

Przeczytaj spokojnie: „dojście jest szacowane”, „dane archiwalne”, „cztery zatwierdzone przejścia”. Nie akcentuj ich jak haseł reklamowych.
